# Employment Application System

## Overview

A digital employment application workflow developed for the ProMed Hospital Services website to streamline applicant information collection and support recruitment operations.

The project integrates a custom employment application form built in Jotform and accessible through the company website.

## Live Website

🔗 https://promedhospitalservices.com/

## Employment Application Form

🔗 https://form.jotform.com/263020852119046

## Project Features

- Online application form
- Resume upload
- AI OCR autofill
- Mobile-friendly design

## Visual Design

Custom website banners and promotional graphics were designed using Canva to support website branding and user engagement.
