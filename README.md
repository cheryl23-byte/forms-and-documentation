# Forms & Documentation Portfolio

This repository showcases professional forms, templates, administrative documentation, and process guides created for business and healthcare-related operations.

## Repository Structure

### Application Forms
Professional application and intake forms.

Examples:
- Employment Application Forms
- Candidate Information Forms
- Interview Evaluation Forms
- Employee Information Sheets

### Templates
Administrative and business document templates.

Examples:
- Meeting Notes Template
- Call Log Template
- Training Checklist
- Document Request Form

### Documentation
Process documentation and standard operating procedures.

Examples:
- Process Guides
- Workflow Documentation
- SOPs
- Training Documentation

## Skills Demonstrated
